# Как выложить DailyTanakh — инструкция

Приложение — **полностью статический сайт** (без сборки, без Node, без базы данных).
Вся папка проекта = готовый сайт. Хостится где угодно, ниже — самые простые варианты.

---

## Вариант 1: GitHub Pages (бесплатно, рекомендуется)

1. Создайте новый репозиторий на GitHub (например, `dailytanakh`).
2. Загрузите проект (git уже инициализирован, первый коммит сделан):
   ```bash
   cd DailyTanakh
   git remote add origin https://github.com/ВАШ_ЛОГИН/dailytanakh.git
   git push -u origin main
   ```
3. В репозитории: **Settings → Pages → Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)** → Save
4. Через 1–2 минуты сайт будет доступен по адресу
   `https://ВАШ_ЛОГИН.github.io/dailytanakh/`

Все пути в приложении относительные, поэтому оно корректно работает и в подпапке
(`…github.io/dailytanakh/`), и на своём домене.

## Вариант 2: Netlify / Vercel / Cloudflare Pages

Перетащите папку проекта в интерфейс (Netlify Drop) или подключите GitHub-репозиторий.
Настройки сборки: **Build command — пусто, Publish directory — корень (`/`)**. Всё.

## Вариант 3: свой сервер

Скопируйте папку и отдавайте её любым веб-сервером (nginx, Apache, Caddy).
Для локального просмотра: `python3 -m http.server 8123` → http://localhost:8123
(открывать через `file://` нельзя — модули и данные грузятся по HTTP).

---

## Что важно знать при обновлениях

- **Версия офлайн-кэша.** После любого изменения файлов приложения или данных
  поднимите номер в первой строке [sw.js](sw.js): `dailytanakh-v7` → `v8` и т.д.
  Тогда у всех пользователей сайт обновится сам (сервис-воркер заменит кэш).
- **PWA.** Сайт устанавливается на телефон/компьютер как приложение и работает офлайн —
  для этого нужен HTTPS (GitHub Pages/Netlify дают его автоматически).
- **Данные.** Тексты лежат в `data/` (готовые JSON). Скрипты в `scripts/` нужны только
  для пересборки данных, на работу сайта не влияют.

## ⚠️ Авторские права — прочитать перед публикацией

В `data/` кроме текстов в общественном достоянии есть материалы с ограничениями:

| Материал | Статус |
|---|---|
| Иврит (масоретский), английский JPS 1917, немецкий Bernfeld/Breuer | Public Domain — можно публиковать |
| Английский перевод Невиим (**Steinsaltz**) | © Steinsaltz Center — для публичного сайта нужно разрешение правообладателя |
| Русский перевод Танаха (ваши .docx) | © правообладатель издания — уточните права на распространение |
| Русские переводы комментариев | производные от текстов выше |

Для **личного/учебного** использования (закрытый репозиторий, свой круг) это обычная практика.
Для **публичного** сайта — либо получите разрешения, либо сделайте репозиторий приватным
(GitHub Pages работает и из приватных репо на платных планах; Netlify — бесплатно).

## Структура проекта (кратко)

```
index.html            вход, import map
sw.js                 сервис-воркер (офлайн-кэш) — здесь версия кэша
manifest.webmanifest  PWA-манифест
data/                 тексты: books.json, text/*.json, commentary/*.json
src/                  код: lib/ (ядро), views/ (экраны), i18n/ (4 языка), styles/
vendor/               Preact/htm/signals (офлайн, без npm)
assets/               шрифты (OFL) и иконки
scripts/              пайплайны данных (Python, только для разработки)
```

Подробности — в [README.md](README.md).
