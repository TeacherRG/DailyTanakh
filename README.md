# DailyTanakh

Минималистичная платформа для **ежедневного изучения Невиим (Пророков) и Ктувим (Писаний)** —
без Торы — в ортодоксальной традиции. Тексты на иврите с огласовками, переводы, классические
комментарии, личные заметки и избранное. Работает полностью **офлайн**.

> 34 книги · 742 главы · 17 360 стихов — реальный текст из проекта **Sefaria**, упакованный в приложение.

---

## Два режима

При первом входе приложение спрашивает, **кто будет учиться** — и дальше режим можно
переключать в настройках (прогресс каждого хранится отдельно):

| | **Взрослый** | **Детский** |
|---|---|---|
| Что читаем | Полный Танах: иврит с огласовками + переводы | 114 историй-пересказов всех Пророков и Писаний |
| Объём | 34 книги · 742 главы · 17 360 стихов | 114 историй · 19 книг · ~510 тыс. знаков |
| Цикл | 1 или 3 года, Невиим и Ктувим параллельно | только годовой (≈ история раз в 3 дня) |
| Особенности | комментарии мудрецов, заметки, избранное, печать, поиск | вопросы для размышления, врезки, награды, любимые истории |
| Оформление | глубокий синий | тёплый янтарный, крупная типографика |

Детский материал — «Иллюстрированная энциклопедия Торы для детей» (© mychitas.app), для 10–15 лет:
каждая история охватывает целую книгу или крупный отрывок Танаха, с разделами, выделенными
мыслями и вопросом для размышления в конце.

## Возможности

- **Циклы изучения** — пройти весь Невиим и Ктувим за **1 год** или **3 года**, по немного каждый день.
- **Главная** — «Чтение на сегодня» (отрывок дня + номер дня цикла), «Сегодня изучают вместе»
  (общий отрывок для всех), «Продолжить чтение» (где остановились), прогресс и серия дней.
- **Читалка** — стих за стихом: иврит (Frank Ruhl Libre, RTL, с огласовками) + перевод; для каждого стиха —
  **комментарии мудрецов** (Раши, Ибн-Эзра, Радак, Мальбим и др.), **личная заметка**, **избранное**, копирование.
- **Печать отрывка** — кнопка печати с выбором (иврит / перевод / комментарии / мои заметки); на лист выводится
  только самое нужное, чисто и аккуратно.
- **Профиль** — заметки, избранные стихи и статистика (прогресс по книгам, серии).
- **4 языка интерфейса** — **русский** (основной), English, Deutsch, **עברית** (с полной поддержкой RTL).
- **Темы** — светлая и тёмная, с плавными переходами; «системная» тема следует ОС.
- **Уведомления** — ежедневное локальное напоминание (пока вкладка открыта).
- **PWA** — устанавливается на телефон/десктоп, работает без интернета.
- **Приватность** — заметки и избранное хранятся только в браузере и никуда не отправляются.

## Запуск

Сборка не нужна — это статическое приложение без зависимостей. Нужен только локальный HTTP-сервер
(модули и `fetch` не работают через `file://`):

```bash
cd DailyTanakh
python3 -m http.server 8123
# откройте http://localhost:8123
```

**Публикация (GitHub Pages / Netlify / свой сервер):** пошаговая инструкция — в [DEPLOY.md](DEPLOY.md).
Там же — про версию офлайн-кэша при обновлениях и про авторские права на тексты.

## Тексты и переводы

Данные загружаются один раз скриптом и сохраняются как статический JSON в `data/` — в рантайме интернет не нужен.

| Язык | Версия | Лицензия | Покрытие |
|------|--------|----------|----------|
| Иврит | Tanach with Nikkud (масоретский текст) | Public Domain | все 34 книги |
| English (Невиим) | **The Steinsaltz Tanakh** (р. Адин Штейнзальц) | © Steinsaltz Center | 21 книга Пророков |
| English (Ктувим) | The Holy Scriptures (JPS 1917) | Public Domain | 13 книг Писаний |
| Deutsch | Die Heilige Schrift (S. Bernfeld, 1902) | Public Domain | 22 книги |
| **Русский** | **Еврейский русский перевод Танаха** (личные файлы пользователя, `.docx`) | © правообладатель | **все 34 книги** |
| Комментарии (Невиим) | **Штейнзальц** — пояснения к разделам (ивр. + англ. + **рус.**) | © Steinsaltz Center | по всем Пророкам |
| Комментарии (Ктувим) | Раши, Ибн-Эзра, Радак, Мальбим и др. (+ **рус. перевод**) | CC-BY / PD | избранные главы |

Русский перевод — полный (34 книги), подключается скриптом [import_ru.py](scripts/import_ru.py) из ваших `.docx`.
Комментарии переведены на русский на **93%** (4262 из 4552 блоков; весь Невиим и почти весь Ктувим) —
где перевода ещё нет, читалка показывает английский или иврит.

**Важно про Невиим (Пророки):** иврит — это всегда точный масоретский пасук (Sefaria). Английский для
Пророков — перевод-пояснение Штейнзальца («еврейский тон»), поэтому он содержит вплетённые пояснения,
как в печатном издании. В ~5 главах (Йеошуа, Шмуэль I, Ирмеяѓу) деление пасуков у Штейнзальца чуть
отличается от масоретского — там английский может на один стих смещаться в конце главы; иврит всегда верен.

> ⚠️ Текст Штейнзальца защищён авторским правом (Steinsaltz Center / Koren). В приложении он используется
> из ваших личных файлов для личного/учебного изучения. Для публичной публикации нужно разрешение правообладателя.

Где перевод недоступен, читалка корректно показывает английский и поясняет это. Источники — **Sefaria** (sefaria.org)
и **Steinsaltz / Chabad.org** (ваши файлы).

### Импорт детской энциклопедии

```bash
python3 scripts/import_kids.py --pdf "/путь/к/Design.pdf" --write
```
Разбирает PDF (114 глав по оглавлению, буквицы, врезки, вопросы) в `data/kids.json`.

### Импорт Штейнзальца

```bash
python3 scripts/import_steinsaltz.py --src "/путь/к/The Steinsaltz Neviim (Prophets)"
```
Накладывает английский Штейнзальца + комментарии + еврейские названия книг поверх масоретского иврита Невиим
(иврит и переводы de/ru остаются от Sefaria).

### Обновить / расширить данные

```bash
python3 scripts/fetch_sefaria.py              # весь корпус + комментарии к избранным главам
python3 scripts/fetch_sefaria.py --books ruth,jonah
python3 scripts/fetch_sefaria.py --force      # игнорировать кэш
```

Чтобы добавить комментарии к другим главам — отредактируйте словарь `FEATURED` в `scripts/fetch_sefaria.py`.

## Технологии

- **Без сборки.** Нативные ES-модули + import map; вендорные **Preact + htm + @preact/signals** в `vendor/`.
- **CSS-дизайн-система** с токенами и темами; анимации на CSS + View Transitions (с учётом `prefers-reduced-motion`).
- **Самохостинг шрифтов** (Inter, Lora, Frank Ruhl Libre — OFL) в `assets/fonts/`.
- **Service worker** (`sw.js`) — офлайн-кэш по принципу «сначала кэш».

## Структура

```
index.html            оболочка, import map, загрузка тем
manifest.webmanifest  PWA-манифест
sw.js                 сервис-воркер (офлайн)
data/                 books.json + text/<книга>.json + commentary/<книга>.json
scripts/              fetch_sefaria.py — пайплайн данных
vendor/               Preact / htm / signals (офлайн)
assets/               шрифты и иконки
src/
  lib/                store, i18n, router, data, schedule, notify, print, util …
  i18n/               ru / en / de / he
  components/         ui (кнопки, лист, переключатели…), chrome (шапка, таб-бар)
  views/              home, reader, library, cycle, profile, settings, about
  styles/             fonts, base (токены/темы), components, print
```
